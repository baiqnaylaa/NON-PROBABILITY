# Analisis Kepuasan Mahasiswa FMIPA terhadap Website Berajah sebagai Media Pembelajaran

__Deskripsi Proyek__

Proyek ini bertujuan untuk menganalisis tingkat kepuasan mahasiswa FMIPA Universitas Mataram terhadap website Berajah sebagai media pembelajaran. Data diperoleh melalui survei online menggunakan Google Form dengan teknik non-probability sampling, yaitu convenience sampling. Analisis dilakukan menggunakan metode naive estimation dan weighted estimation.

__Tujuan__
Mengetahui tingkat kepuasan mahasiswa terhadap website Berajah.
Membandingkan hasil naive estimation dan weighted estimation.
Menilai pengaruh pembobotan terhadap hasil estimasi.

__Dataset__

Data yang digunakan merupakan data primer dari 36 responden mahasiswa FMIPA Universitas Mataram.

__Metode Analisis__
-Analisis deskriptif

-Naive Estimation

-Weighted Estimation

-Perbandingan Estimasi

__Hasil Utama__

-Tingkat kepuasan tertinggi terdapat pada kemudahan mengakses materi perkuliahan (Y3) sebesar 70,1%.

-Tingkat kepuasan terendah terdapat pada kestabilan website (Y7) sebesar 27,0%.

-Rata-rata weighted estimation sebesar 53,0%, yang menunjukkan bahwa lebih dari separuh mahasiswa merasa puas terhadap website Berajah.
